# eBooks on iPods

Carried over from the v1 task list. These notes were written during v1 and have **not** been independently re-checked. Treat them as leads.

| Device or firmware | EPUB | Plain text | Limit | How it works |
| --- | --- | --- | --- | --- |
| iPod classic, stock firmware | No | Yes, through Notes | 4 KB per file | Files go in the `Notes/` folder on the iPod drive and show under Extras, Notes. Longer books have to be split into chained files under 4 KB with next and previous links. |
| iPod classic, Rockbox firmware | No, unless a fork | Yes | None | Rockbox ships a Text Viewer plugin with word wrap, font sizes and bookmarks, and a SpeedReader plugin that flashes words one at a time. |
| iPod classic, PodBox (Rockbox fork) | Yes | Yes | None | Adds an EPUB reader with reading progress. |
| iPod classic, audiobook (M4B) | n/a | n/a | n/a | Native `.m4b` files with chapter markers and remembered position. Likely the best reading experience on a classic. |
| iPod touch | Yes | Yes | None | Apple Books reads EPUB and PDF. |

The nano 7th generation is not in this table. The Apple specification page for it mentions neither Notes nor books, so eBooks on that model are an open question.
